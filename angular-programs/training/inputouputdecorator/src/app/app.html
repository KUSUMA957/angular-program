🚀 Angular @Output() Decorator Demo

Demonstrates data flow from Child Component → Parent Component using Events

📘 How @Output() Works:

  • Child Component: Uses @Output() decorator with EventEmitter
  • Event Emission: Child calls emit() to send data to parent
  • Parent Listening: Parent uses (eventName)="handler($event)" to receive data
  • Data Flow: Child → Parent (upward communication)
